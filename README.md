  # Nocturne

  Small visual experiments built with React and SCSS.

  <br />

  A collection of self-contained visual pieces exploring atmosphere, motion,
  <br />
  and abstraction using CSS gradients, keyframe animation, blur, blend modes,
  <br />
  and layered movement.

  <br />

  **How it works**
</div>

<br />

<div align="center">
  Each experiment is a single React component with all motion handled entirely
  through CSS.

  Layered gradients, blur, blend modes, and long-duration keyframes create the
  movement and depth.

  <br />

  No canvas. No WebGL. No animation libraries. Just CSS doing more than it's
  usually asked to.
</div>
